# 💾 Disk Speed Monitor — следи за скоростью своих дисков в реальном времени

> «Узнай, насколько быстр твой SSD или HDD»

**Disk Speed Monitor** — это набор консольных утилит для мониторинга скорости чтения и записи дисков в реальном времени.  
Программа позволяет отслеживать производительность дисков, выявлять узкие места и диагностировать проблемы.

## 🚀 Особенности
- 📊 Отображение скорости чтения и записи в реальном времени.
- 📈 Поддержка нескольких дисков одновременно.
- 🎨 Цветовая индикация: зелёный — отлично, жёлтый — средне, красный — медленно.
- 💾 Экспорт данных в CSV и JSON (где реализовано).
- ⏱️ Настройка интервала обновления.
- 📋 Подробная статистика: средняя скорость, пиковая скорость, общий объём данных.
- 🖥️ Поддержка всех основных ОС (Windows, Linux, macOS).

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости.

| Язык       | Библиотека/пакет                     | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | `psutil`                             | `python disk_speed.py`                  |
| Go         | `github.com/shirou/gopsutil/v3`      | `go run disk_speed.go`                  |
| JavaScript | `node-disk-info`, `ps-list`          | `node disk_speed.js`                    |
| Java       | `oshi`                               | `javac -cp .:oshi-core.jar ... && java disk_speed` |
| C#         | `System.Management`                  | `dotnet run`                            |
| Rust       | `sysinfo`                            | `cargo run`                             |
| Ruby       | `sys-proctable`, `sys-filesystem`    | `ruby disk_speed.rb`                    |
| PHP        | `exec` + `iostat`/`wmic`             | `php disk_speed.php`                    |
